⏱️ 考场3分钟决策 — 看到简答题先问3个问题

看到题目 → Q1: 介绍事物本身？ 特点/特征/构成/分类 ➜ 模式A·分解
↳ 不行→ Q2: 说明怎么做？ 方法/途径/措施/要求 ➜ 模式B·流程
↳ 还不行→ Q3: 解释为什么/有什么用？ 功能/作用/意义/因素 ➜ 模式C·因果

💡 99%的简答题都可用这3步 → 选模式 → 套句式 → 填内容

💡 核心思路：别管具体问法，所有简答题只分3种逻辑

不需要背6种模板。任何简答题的答案，底层都是这3种逻辑之一。判断题目要你"说什么"比判断"什么问法"更重要。

看到题目 → 要我"介绍事物本身"？ → 模式A: 分解式 → 要我"说明怎么做"？ → 模式B: 流程式 → 要我"解释为什么/有什么用"？ → 模式C: 因果式

模式A · 分解式 — "这个东西由哪些部分/类型/特点组成？"

适用问法：简述...的特点/特征/构成/分类/种类/类型/内容/表现/环节

万能拆解维度（按"人-事-物-时"四维往下拆）：

👤 主体维
谁参与？有什么特征？教师/学生/内容的特性
📋 属性维
按性质/类型/层次怎么分？每个类别是什么
⏳ 过程维
按时间/阶段/步骤怎么分？先后顺序是什么
🎯 功能维
按作用/目的怎么分？对谁有什么效果

万能句式："从___角度看，...表现为/包括/分为..." × 4-5个角度 = 4-5个得分点

📌 真题套用示例：

例1: "人格的特征" → 主体(独特性-每个人不同) + 属性(稳定性-跨时间一致) + 过程(统合性-各特质整合) + 功能(功能性-影响行为) + 属性(社会性-后天形成) + 属性(复杂性-多面统一) = 6个得分点

例2: "综合实践活动课程的特点" → 属性维(整体性-多学科整合) + 过程维(实践性-亲身经历) + 属性维(开放性-目标内容多元) + 过程维(生成性-动态生成) + 主体维(自主性-学生自主选择) = 5个得分点

例3: "学科课程的特点" → 属性维(逻辑性-按学科逻辑) + 功能维(系统性-系统知识) + 功能维(简约性-高效获取) = 3个得分点

例4: "注意的品质" → 属性维(广度-范围大小) + 过程维(稳定性-持续时间) + 功能维(分配-多任务) + 过程维(转移-任务切换) = 4个得分点

模式B · 流程式 — "这件事怎么做/要达到什么标准？"

适用问法：简述...的方法/途径/措施/要求/标准/原则/策略

万能流程链（从准备到收尾走一遍）：

① 前提/准备
先明确什么？准备什么？ → ② 内容/对象
做什么？对谁做？ → ③ 方法/手段
用什么方式？怎么操作？ → ④ 过程/步骤
按什么顺序？注意什么？ → ⑤ 结果/评价
达到什么效果？怎么检查？

万能句式："要做到/实现___，需要在___方面___" × 4-5个流程节点 = 4-5个得分点

📌 真题套用示例：

例1: "一堂好课的基本标准" → ①准备(目的明确) → ②内容(内容正确) → ③方法(方法得当) → ④过程(结构合理) → ⑤表达(语言艺术) → ⑥氛围(气氛热烈) → ⑦板书(板书有序) → ⑧态度(态度从容) = 8个得分点

例2: "布置作业的基本要求" → ①内容(符合课标) → ②分量(难易适度) → ③要求(明确+时间) → ④反馈(清晰及时) = 4个得分点

例3: "启发性教学原则的基本要求" → ①前提(调动主动性) → ②方法(启发独立思考) → ③过程(让学生动手) → ④氛围(发扬教学民主) = 4个得分点

例4: "班主任培养班集体的方法" → ①前提(确定目标) → ②核心(建立班委) → ③基础(建立秩序) → ④载体(组织活动) → ⑤导向(培养舆论) = 5个得分点

模式C · 因果式 — "这个东西为什么重要/有什么用/受什么影响？"

适用问法：简述...的功能/作用/意义/任务/因素/原因/条件/规律

🔍 近端→远端
直接影响是什么？长远影响是什么？
👤 个体→群体→社会
对一个人？对一群人？对整个系统？
💡 理论→实践
知识层面？行为层面？结果层面？
➕ 直接→间接
本来就要达成的？附带产生的？

万能句式："___对___具有___作用/影响，具体表现为___" × 3-5个层次 = 3-5个得分点

📌 真题套用示例：

例1: "教育的文化功能" → 近端直接(传递保存-把文化传下去) → 空间扩展(传播交流-跨区域流动) → 纵向发展(选择提升-取其精华) → 长远创新(更新创造-文化非静止) = 4个得分点

例2: "教育促进社会生产力发展" → 直接功能(劳动力再生产-培养工人) → 间接功能(科学知识再生产-传播科技) → 创新功能(技术创新-研发新技术) = 3个得分点

例3: "教学的作用/意义" → 直接(传播知识促发展) → 核心(实现培养目标的基本途径) → 地位(学校中心工作) = 3个得分点

例4: "学校美育的基本任务" → 知识层(传授美学知识) → 能力层(培养审美+创造美) → 人格层(内外美统一) = 5个点，从基础到高级
