🔵 低概率 1.5 教育制度(学制/义务教育) — 可能方向：学制沿革、义务教育特点
📋 简述我国现行学制及义务教育的特点。
(1)我国现行学制是分支型学制（从单轨制发展而来的分支制），包括：学前教育→初等教育（小学6年）→中等教育（初中3年+高中3年，含普通高中和职业高中）→高等教育（专科/本科/研究生）。
(2)义务教育的强制性：国家以法律形式规定适龄儿童必须接受，国家、社会、学校、家庭必须予以保障。
(3)义务教育的普及性（普遍性）：所有适龄儿童不受性别、民族、地域等限制，一律平等接受教育。
(4)义务教育的免费性：国家对接受义务教育的学生免收学费，逐步实现免费提供教科书和其他费用减免。
(5)义务教育的基础性：义务教育是基础教育的重要组成部分，为学生的终身发展奠定基础。
🧠 口诀：学制：学分支→初(6)→中(3+3)→高(专本研)；义务教：强制+普及+免费+基础
🔵 低概率 1.7 教育研究方法 — 可能方向：观察/调查/实验/行动研究法
📋 简述教育研究的基本方法。
(1)观察法：有目的有计划地观察研究对象，获得事实材料。分参与观察和非参与观察。优点是自然真实，缺点是只能观察表面行为。
(2)调查法：通过问卷、访谈等方式收集资料。优点是效率高、范围广，缺点是受被调查者主观因素影响。
(3)实验法：控制变量、操纵自变量、观测因变量，揭示因果关系。优点是科学性强，缺点是有时不符合教育伦理。
(4)行动研究法：一线教师在真实教育情境中发现问题、分析问题、解决问题，边行动边研究。
(5)个案研究法：对个体/群体/组织进行深入全面研究。优点是深入了解，缺点是代表性不足难以推广。
🧠 口诀：观(观察)+调(调查)+实(实验)+行(行动)+个(个案)

🔥 极可能考 3.2 教学过程规律 — 可能方向：教学过程基本规律(4条)、教学过程本质
📋 简述教学过程的本质及基本规律。
(1)教学过程的本质：①教学过程是一种特殊的认识过程（以间接经验为主、有教师指导、有教育性）；②教学过程是促进学生发展的过程（掌握知识的同时发展能力、培养品德）。
(2)间接经验与直接经验相统一（间接性规律）：以学习间接经验（书本知识）为主，同时需要一定的直接经验为基础，两者有机结合。
(3)掌握知识与发展能力相统一（发展性规律）：知识是能力发展的基础，能力发展反过来促进知识的掌握，两者相互促进。
(4)教师主导与学生主体相统一（双边性规律）：教师在教学过程中起主导作用，学生是学习的主体，两者辩证统一。
(5)传授知识与思想教育相统一（教育性规律）：教学永远具有教育性，知识传授本身就蕴含着思想道德教育，两者不可分割。
🧠 口诀：本质：特认+促发；规律：间(间接)+发(发展)+主(主导)+思(思想)
🔥 极可能考 3.5 教学组织形式 — 可能方向：班级授课制优缺点、分组教学/特朗普制
📋 简述班级授课制的优缺点及教学组织形式改革。
(1)优点：①效率高，一位教师同时教授几十名学生；②系统性，按课程计划和课程标准有组织教学；③集体性，发挥班集体教育作用；④利于教师主导作用的发挥。
(2)缺点：①难以照顾个体差异（统一进度、统一要求）；②不利于实践能力培养（以教师讲授为主）；③学生主体性受限（被动接受多）；④教学内容与方式灵活性不足。
(3)分组教学：按学生能力或成绩分水平组教学，分为外部分组（跨班）和内部分组（班内分层）。
(4)特朗普制：大班上课（40%）+小班讨论（20%）+个人独立研究（40%）相结合，灵活安排教学时间。
(5)道尔顿制：废除班级授课制，学生自主学习、与教师签订学习合同，按自己的进度完成学习任务。
🧠 口诀：班：效系集导；缺点：不因不实不被不灵；改革：分组+特(大班小班个研)+道(合同)
🔥 极可能考 3.6 教学评价 — 可能方向：诊断/形成/总结性评价
📋 简述教学评价的类型及其功能。
(1)诊断性评价（课前/学初）：了解学生知识基础和准备情况，为教学起点提供依据。如入学摸底考试。
(2)形成性评价（课中/学中）：在教学过程中及时了解学习状况，发现问题并调整教学。如课堂提问、单元测验。
(3)总结性评价（课后/学期末）：在教学结束后对学习成果做出全面判断。如期末考试、毕业会考。
(4)相对性评价（常模参照）：将个体成绩与群体平均成绩比较，确定相对位置。如高考排名。
(5)绝对性评价（目标参照）：将个体成绩与预设标准比较，判断是否达标。如会考、资格考试。
🧠 口诀：时：诊断(前)+形成(中)+总结(后)；参照：相对(比人)+绝对(比标准)

(4)教育启示：引导学生将失败归因于努力不足（可控因素），而非能力不足，以保护学习动机和自我效能感。

看到题目 → Q1: 介绍事物本身？ 特点/特征/构成/分类 ➜ 模式A·分解
↳ 不行→ Q2: 说明怎么做？ 方法/途径/措施/要求 ➜ 模式B·流程

💡 99%的简答题都可用这3步 → 选模式 → 套句式 → 填内容

💡 核心思路：别管具体问法，所有简答题只分3种逻辑

不需要背6种模板。任何简答题的答案，底层都是这3种逻辑之一。判断题目要你"说什么"比判断"什么问法"更重要。

看到题目 → 要我"介绍事物本身"？ → 模式A: 分解式 → 要我"说明怎么做"？ → 模式B: 流程式 → 要我"解释为什么/有什么用"？ → 模式C: 因果式

模式A · 分解式 — "这个东西由哪些部分/类型/特点组成？"

适用问法：简述...的特点/特征/构成/分类/种类/类型/内容/表现/环节

万能拆解维度（按"人-事-物-时"四维往下拆）：

👤 主体维
谁参与？有什么特征？教师/学生/内容的特性
📋 属性维
按性质/类型/层次怎么分？每个类别是什么
⏳ 过程维
按时间/阶段/步骤怎么分？先后顺序是什么
🎯 功能维
按作用/目的怎么分？对谁有什么效果

万能句式："从___角度看，...表现为/包括/分为..." × 4-5个角度 = 4-5个得分点

📌 真题套用示例：

例1: "人格的特征" → 主体(独特性-每个人不同) + 属性(稳定性-跨时间一致) + 过程(统合性-各特质整合) + 功能(功能性-影响行为) + 属性(社会性-后天形成) + 属性(复杂性-多面统一) = 6个得分点

例2: "综合实践活动课程的特点" → 属性维(整体性-多学科整合) + 过程维(实践性-亲身经历) + 属性维(开放性-目标内容多元) + 过程维(生成性-动态生成) + 主体维(自主性-学生自主选择) = 5个得分点

例3: "学科课程的特点" → 属性维(逻辑性-按学科逻辑) + 功能维(系统性-系统知识) + 功能维(简约性-高效获取) = 3个得分点

例4: "注意的品质" → 属性维(广度-范围大小) + 过程维(稳定性-持续时间) + 功能维(分配-多任务) + 过程维(转移-任务切换) = 4个得分点
